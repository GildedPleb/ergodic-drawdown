# K6: Large A (V32-BUILD:832, :866)

Grading notes for Probe. The large mark (Swatches) only; the default size stays 11/1/2/5.

- **Mark** (`CheckMark.module.css`, `data-size="large"`): 20/2/3/10 px (box, stroke, gap, core):
  `--_mark: 1.25rem`, `--_line: 2px`, `--_gap: 3px`. The core is the content box (20 − 2 × (2 + 3)).
  One stroke and one gap per size: padding and outline-offset both read `--_gap`.
- **Hover** (fine pointer, enabled parent; K5): the stroke again, `var(--_line) solid currentColor`,
  a gap out (3px), in the swatch's own colour.
- **Focus** (`Swatches.module.css`): `--focus-w` (2px) `--focus` at `--s-2` (8px = 3 + 2 + 3) on the
  mark wrapper, a 3px gap past the hover ring: 40px overall, inside the 44px target. Layout and
  targets are unchanged.
- **Disabled**: dashed, no ring. Swatches never disable a chip, so the sheet's disabled states are
  the `check-mark/large-disabled(-on)` stories; the visual test draws them in `--disabled`, as a
  disabled parent sets it.
- **Contrast** (`test/v2/contrast.test.ts`): the 8 swatch colours and `--disabled` are at least 3:1
  on `--surface` and `--ground` in both themes. Lowest: linen `--disabled` on surface 3.53, plan-1
  on linen surface 3.55, dark `--disabled` on surface 3.63.
- **Baselines** (`k6-large.pw.ts`, Chromium 390 and 1440, dark and linen):
  `k6--swatch-{off,on,hover,hover-on,focus-on,focus-hover}--<theme>.png`,
  `k6--large-disabled[-on]--<theme>.png` (44px clips centred on the mark).
- **Against the sheet** (`p3/large-mark/sheet-{dark,linen}.png`, column Large A, box Playwright
  1.64.1, Chromium): every state at 1× matches pixel for pixel (DPR 2, both themes). At 4× (drawn as
  the sheet draws it, CSS lengths × 4 at DPR 2) every state matches once the sheet's crop is moved
  up one device pixel; the sheet places its 4× row at y = 506.28125 CSS px, so its edges snap one
  device row higher. Nothing was tuned to the mock.
