# StackMath v2 · Tokens (two tiers)

`tokens/`, built for Keel. The old files (`color/color.css`, `system/space.css`, `type/type.css`) are **untouched**.

| File                           | Tier         | Contains                                                                                                                                                                                                                                                                              |
| ------------------------------ | ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

## Rules

- Components use **semantic** tokens, plus motion-etc, type and space. They never use `--gold-225`-style palette names.
- No raw colour, alpha or mix value appears outside `palette.css`. Raw values in `motion-etc.css` are non-colour primitives with no theme variation.
- **Theme switch:** `data-theme="linen"` on `<html>` (or any subtree) replaces the old `.linen` class.
- **Shape:** `--radius-0` everywhere. **Shadow:** `--shadow-none` by default, with `--shadow-sheet` as the single allowed shadow (the locked v32 bottom dock).

- **v39 aliases** (`--bg --muted --line --chip --loss`) are dropped in favour of the semantic names. `--text` and `--rule` keep their names but are now the semantic tokens.

## v2 repo additions (Form + Keel rulings, 2026-10-19)

- **`--invalid`** (semantic, both themes) = the same palette entry as `--text` (dark `--linen-75`, linen `--umber-800`). A field's invalid state is a `--rule-strong` border in `--invalid`, a ⚠ SVG icon (Icon `warning`), and a plain-language message (the cause and the next step) wired with `aria-describedby` and `aria-invalid`.
